# Core Demo Project 🚀

Bu proje, **ASP.NET Core Identity** kullanarak geliştirdiğim kullanıcı yönetimi ve rol bazlı yetkilendirme sistemi içeren bir web uygulamasıdır.  
Projeyi **.NET 8** ile geliştirdim ve Azure App Service üzerinde canlıya aldım.

## 🔧 Kullanılan Teknolojiler
- C# & .NET 8
- ASP.NET Core Identity
- Entity Framework Core
- SQL Server
- Azure App Service (Deployment)

## 📌 Özellikler
- Kullanıcı kayıt & giriş
- Rol bazlı yetkilendirme (Admin / User)
- CRUD operasyonları
- SQL Server ile veri yönetimi
- Azure üzerinde deploy edilmiş canlı sürüm


## 🎯 Hedef
Bu proje ile:  
- Backend geliştirme (C#, .NET 8)  
- Authentication & Authorization (Identity)  
- Deployment (Azure App Service)  
konularında deneyim kazandım.
